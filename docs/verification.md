## 翻译质量核对

以下为实际模型输出的人工核对，详细原文与输出保存在源码目录 `docs/translation-review.json`。

| 样例 | 核对结果 |
|---|---|
| GPIO 初始化、GPIO 参数 | 意思基本可辨，“peripheral”译为“外围”，术语提示应读作“外设” |
| GPIO 引脚宏参数 | GPIO_Pin、GPIO_PIN_0、GPIO_PIN_5 保留，部分 Pin 未翻译 |
| GPIO 电平读取 | pin 被误译为“指针”，应读作“引脚” |
| GPIO 上拉输入 | pull-up resistor 误译，必须结合“上拉电阻”术语提示和原文 |
| 定时器预分频范围 | 0 至 65535 完整保留，“预缩放”应读作“预分频” |
| TIM_Period 设置 | 参数名、999 和操作先后关系保留 |
| 更新中断 | 仅清除标志后才能使能的条件仍可辨，语序生硬 |
| PWM 占空比 | 50 保留；duty cycle、square wave 分别误译为“值班周期”“平面波”，正确为“占空比”“方波” |
| HAL_TIM_Base_Start_IT() 调用 | 保护校验失败，整句保留原文并提示 |
| 禁止提前使能中断 | 否定条件及配置优先级的先后关系保留 |
| 清除中断标志 | 意思可辨，“旗”应读作“标志” |
| DMA 缓冲区有效期 | 保持有效直到传输结束的条件保留，transfer 译法生硬 |
| DMA 传输方向 | 外设到内存方向保留 |
| DMA 循环模式 | 自动重启含义保留 |
| ADC 转换 | “转换旗结束”语序不准确，应理解为等待转换结束标志 |
| 串口超时 | 参数名、超时和毫秒单位保留 |
| HAL_OK 返回值 | 成功含义保留 |
| HAL_BUSY 返回值 | 上一次操作仍在进行的含义可辨，transfer 被译为“调剂” |
| 地址与位掩码 | 0x40020000 和位 7 完整保留 |
| 多行注释与声明 | 标签和函数声明完整；reset、handle 被误译，应对照“复位”“句柄”术语 |

内置术语与用户术语在结果旁提示，不强制修改模型句子。这一版适合辅助阅读，专业翻译质量仍有限；不能将“出现中文”作为语义准确的证明。

- 未完成 VS Code、PDF 阅读器的实际复制流程测试；Keil 只观察到快捷键唤起，未修改用户工程。
- 多显示器负坐标边界有算法测试，未在多台不同缩放比例的显示器上完成硬件验证。
- 内存与耗时是本机短注释样例的测量值，长文本、其他 CPU 和首次磁盘读取会有差异。
- 未对程序进行代码签名；首次运行可能出现 Windows 的发布者提示。
